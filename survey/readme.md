
# Survey
This folder contains the scripts and raw data from the survey.

## Structure

```text
├── data
│   ├── P5_Dependencies_raw.csv
│   └── completed_responses_qualitative.csv
├── eda.ipynb
├── readme.md
└── survey.pdf
```
## Details
* `data` folder contains the raw data (`P5_Dependencies_raw.csv`) and the qualitative data (`completed_responses_qualitative.csv`).
* `eda.ipynb` is a notebook that processes the raw data and created the charts used in the paper.
* `survey.pdf` contains the complete questionnaire used to evaluate the proposed taxonomy.
