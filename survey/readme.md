
# Survey
This folder contains the scripts and raw data from the survey.

## Structure

```text
├── data
│   ├── P5_Dependencies_raw.csv
│   └── completed_responses_qualitative.csv
├── eda.ipynb
└── readme.md
```
## Details
* The `data` folder contains the raw data (`P5_Dependencies_raw.csv`) and the qualitative data (`completed_responses_qualitative.csv`).
* The `eda.ipynb` is a notebook that processes the raw data and created the charts used in the paper.
